# 本机运行依赖与清理

公开源码目录不是运行依赖。已安装程序在系统 EFI 分区的 `\EFI\TU102Unlock\AUTO.EFI`，固件载荷嵌在 EFI 内；同目录 `AUTO.ENABLED` 标记也需要保留。正常启动还依赖已登记的 UEFI 启动项、原 Windows Boot Manager、兼容显卡/主板/驱动状态。

本机正常运行不读取 E 盘工程、编译器、Python、研究仓库或 U 盘。测试和恢复脚本仍可能引用原工程路径；删除原目录后那些旧脚本不能继续照原路径运行，但开机解锁本身不受影响。

| 内容 | 是否可清理 | 作用 |
|---|---|---|
| E 盘旧研究仓库、旧测试/编译产物、临时文件 | 备份后可清理 | 研究和开发材料 |
| 公开源码包 | 可移走/另存 | GitHub 发布与继续开发 |
| 本机私人备份 | 不要求在线，但建议异地留一份 | 原 EFI、原 Boot 变量、ROM、输入和恢复材料 |
| EFI 分区的 `EFI/TU102Unlock` | 正常使用时必须保留 | 真正运行的程序和标记 |
| 已配置的自动 UEFI 启动项 | 正常使用时必须保留 | 每次启动执行 EFI |
| 原 Windows Boot Manager | 必须保留 | 系统启动与恢复 |
| 本机已验证的驱动/GSP 设置 | 保持当前状态 | 改动后需重新验证 |

工程占用和启动分区是不同位置；不要因为清理 E 盘而去删启动分区。私人备份含 ROM/固件/分区信息，不上传 GitHub。
